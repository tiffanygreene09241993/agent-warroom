# AGENT WARROOM

**Command. Compete. Conquer.**

AGENT WARROOM is a futuristic, real-time multiplayer strategy game where rival factions compete for control of a dynamic digital battlefield.

## Features

- Real-time multiplayer rooms
- Four competing factions: ATLAS, PHANTOM, NOVA, and ORACLE
- Strategic territory capture and defense
- Scouting, influence, and fortification mechanics
- Autonomous AI-controlled factions
- Live event feed and shared battlefield updates

## Tech Stack

- Node.js
- Express
- Socket.IO
- HTML, CSS, and JavaScript

## Getting Started

```bash
npm install
npm start
```

Open `http://localhost:3000` in your browser.

## Deployment

Designed for deployment on platforms such as Render.

See the project README and deployment instructions for configuration details.
